# Support Ammo Box Medical Supply

This mod gives the **Support Ammo Box** an additional healing function.

The Ammo Box keeps its original ammunition resupply functionality while also healing nearby friendly players.

### Features

* Resupplies ammunition and gadgets as normal.
* Heals nearby friendly players.
* Uses Battlefield 3's native supply and healing system.
* No changes to the Ammo Box model or deployment behavior.

### Healing Settings

```lua
healing.radius = 3.5
healing.supplyIncSpeed = 12.0
healing.infiniteCapacity = true
healing.supplyPointsRefillSpeed = 0.0
healing.supplyPointsCapacity = 1.0
```

**In short:**

> **Support Ammo Box = Ammo Supply + Medical Supply**
